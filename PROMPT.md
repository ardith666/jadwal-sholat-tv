# The Prompt

**First, on the TV:** Settings → System → About → press OK on **Build** 7 times → back → Developer
options → turn on **USB debugging**. Keep the TV on, on the same Wi-Fi as your computer.

Then paste this into Claude Code / Antigravity / Cursor:

```text
Find my Android TV on my local Wi-Fi, connect over ADB, build the Jadwal Sholat TV app from this repository, and install it on the TV.

The app features:
1. Full-screen Islamic ambient kiosk display with digital clock and accurate Indonesian prayer times (MyQuran/Kemenag for 514 cities).
2. Countdown timer when less than 5 minutes remain before adzan.
3. Audio adzan / beep alert when prayer time arrives.
4. Rotating Quran verses at the bottom (Arabic Utsmani, Latin transliteration, and Indonesian translation).
5. Remote D-pad friendly settings dialog: location picker, audio mode toggle, verse display options, and 'Keep Screen On' (anti-sleep).
6. Verify installation by launching the app and taking a screenshot from the TV.
```
